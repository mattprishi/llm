# Пилоты GPU 1

На одной NVIDIA A100-SXM4-80GB. Результаты ниже использовались для выбора лимита и оценки времени; пилоты не входят в итоговую таблицу BFCL.

| Пилот | Лимит новых токенов | Завершённые шаги | Обрезанные ответы | Шаги с ненулевым градиентом | Медиана после первого шага |
|---|---:|---:|---:|---:|---:|
| `pilot2` | 192 | 6 | 10/24 | 2/6 | 7,69 с |
| `pilot256` | 256 | 6 | 2/24 | 4/6 | 7,73 с |
| `pilotfast` | 256 | 1 из 5 | 0/4 на единственном завершённом шаге | 0/1 | нет измерения |

Первые два пилота стартовали с одной модели, одного seed и того же порядка групп. Увеличение лимита исправило несколько обрезаний без заметного изменения медианы на таком коротком пилоте. Это измерение режима обучения, финальная оценка использует штатные 1024 токена.

Первую попытку остановил отсутствующий `Python.h` при компиляции Triton. Заголовки Python 3.12 извлекли в папку эксперимента и подключили через `CPATH`. Ускоренный вариант с FLA и causal-conv1d был остановлен лимитом времени на первом цикле компиляции и не использован для основных прогонов. Для оценки используется отдельный vLLM. Первая попытка BFCL не завершилась из-за сборки FlashInfer sampler без `nvcc`; все зачтённые оценки запускаются с одной настройкой `VLLM_USE_FLASHINFER_SAMPLER=0`.
