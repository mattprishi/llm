Цель домашнего задания
Научиться дообучать небольшую языковую модель (Qwen2.5-0.5B-Instruct) методом Supervised Fine-Tuning (SFT), чтобы она корректно вызывала функции (function calling) для управления умным домом: выбирала подходящие функции, передавала правильные аргументы и обрабатывала результаты их выполнения.
Краткое описание задачи
Студентам необходимо реализовать основные этапы дообучения модели и создания агента:
Настроить генерацию ответов — подготовить запрос с помощью chat template и схем функций, реализовать генерацию с корректной остановкой.
Разобраться в обучающих данных — изучить структуру диалогов, вызовы функций, результаты их выполнения и назначение разных типов примеров.
Настроить маску loss — изменить chat template так, чтобы модель обучалась предсказывать только собственные ответы и вызовы функций, а не сообщения пользователя и результаты выполнения функций.
Дообучить модель — настроить SFTTrainer, провести обучение всех весов модели и сохранить результат.
Оценить качество — сравнить исходную и дообученную модели по корректности выбора функций и их аргументов на тестовых запросах.
Реализовать агентный цикл — обеспечить полный цикл работы: модель формирует вызов, функция выполняется в симуляторе, результат добавляется в историю диалога, после чего модель продолжает работу.
Итоговый результат: работающая дообученная модель и агент, который выполняет команды пользователя в симуляторе умного дома, корректно обрабатывает несколько вызовов функций за один ход и не вызывает неподходящие функции для неподдерживаемых запросов.
